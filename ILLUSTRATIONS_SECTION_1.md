### Leçon 1.1 : Qu'est-ce que le HTML ?

#### 1. **Schéma : Architecture Client-Serveur**
**Type** : Diagramme technique
**Description** :
- Montrer le cycle : Navigateur (Client) ↔ Internet ↔ Serveur

**Recherche suggérée** : "client server architecture diagram simple"

**Dimensions** : 800x400px minimum
**Nom du fichier** : `client-server-architecture.png`

#### 2. **Infographie : HTML vs CSS vs JavaScript**
**Type** : Infographie comparative
**Description** :
- 3 colonnes côte à côte
- Colonne 1 : HTML (Structure) - Icône de squelette/fondations
  - Rôle : Contenu et structure
  - Exemple : `<h1>`, `<p>`, `<div>`
- Colonne 2 : CSS (Présentation) - Icône de pinceau/palette
  - Rôle : Style et apparence
  - Exemple : couleurs, fonts, layouts
- Colonne 3 : JavaScript (Comportement) - Icône d'éclair/engrenage
  - Rôle : Interactivité
  - Exemple : animations, événements, AJAX

**Analogie visuelle** :
- HTML = Murs de la maison
- CSS = Décoration
- JS = Électricité/domotique

**Recherche suggérée** : "html css javascript difference infographic"
**Format** : PNG
**Dimensions** : 1200x600px minimum
**Nom du fichier** : `html-css-js-comparison.png`

---

#### 3. **Timeline : Évolution du HTML**
**Type** : Frise chronologique
**Description** :
- Axe horizontal du temps : 1991 → 2024
- Points clés :
  - 1991 : HTML 1.0 (Tim Berners-Lee)
  - 1995 : HTML 2.0 (formulaires)
  - 1997 : HTML 3.2 (scripts, CSS)
  - 1999 : HTML 4.01
  - 2000 : XHTML 1.0 (strict)
  - 2014 : HTML5 (révolution : video, canvas, APIs)
  - Aujourd'hui : Living Standard
- Icons pour chaque version
- Code couleur progressif (ancien en gris → moderne en couleur)

**Recherche suggérée** : "html history timeline evolution"
**Format** : PNG ou SVG
**Dimensions** : 1400x300px
**Nom du fichier** : `html-evolution-timeline.png`

### Leçon 1.2 : Structure de base d'une page HTML

#### 4. **Diagramme : Anatomie d'une page HTML**
**Type** : Schéma structurel annoté
**Description** :
- Code HTML à gauche avec annotations à droite
- Surligner chaque partie importante :
  - `<!DOCTYPE html>` → "Déclaration HTML5"
  - `<html lang="fr">` → "Racine du document"
  - `<head>` → "Métadonnées (invisible)" avec flèche vers zone
    - `<meta charset>` → "Encodage"
    - `<meta viewport>` → "Responsive"
    - `<title>` → "Titre de l'onglet"
  - `<body>` → "Contenu visible" avec flèche vers zone
    - `<h1>`, `<p>` → exemples

**Style** : Schéma propre, couleurs douces, annotations claires
**Recherche suggérée** : "html document structure anatomy diagram"
**Format** : PNG ou SVG
**Dimensions** : 900x700px
**Nom du fichier** : `html-document-anatomy.png`

---

#### 5. **Infographie : Métadonnées importantes**
**Type** : Carte visuelle / Mindmap
**Description** :
- Centre : Balise `<head>`
- Branches partant du centre :
  - **charset** : Support des caractères (émojis, accents)
  - **viewport** : Responsive mobile
  - **title** : SEO + Onglet navigateur
  - **description** : Snippet Google
  - **author** : Auteur de la page
  - **keywords** : Mots-clés SEO
  - **og:*** : Réseaux sociaux
- Chaque branche avec icône et exemple de code

**Recherche suggérée** : "html meta tags infographic"
**Format** : PNG
**Dimensions** : 1000x800px
**Nom du fichier** : `html-meta-tags-mindmap.png`

#### 6. **Comparaison : Avec/Sans Viewport sur mobile**
**Type** : Comparaison visuelle (before/after)

**Recherche suggérée** : "viewport meta tag mobile comparison"

**Dimensions** : 800x500px
**Nom du fichier** : `viewport-mobile-comparison.png`

## 🎨 Recommandations de style

- **Couleurs** : Palette cohérente (bleu pour HTML, vert pour validé, rouge pour erreur)
- **Fonts** : Lisibles (Roboto, Open Sans, Inter)
- **Style** : Moderne, épuré, professionnel
- **Format** : PNG pour photos, SVG pour diagrammes si possible
- **Compression** : Optimiser les images (TinyPNG, ImageOptim)
